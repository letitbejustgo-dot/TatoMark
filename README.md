# TatoMark · Direct2D 原生版（GPU 合成）

用 **Win32 + Direct2D + DirectWrite** 重写的原生版本，用于和 Python(tkinter/Pillow) 版对比"丝滑度"。核心区别：桌面被当作 GPU 纹理，变暗、选区提亮、放大镜缩放全部由 GPU 合成，几乎不吃 CPU。

## 运行

直接双击 `TatoMarkD2D.exe`。进入后：
- 鼠标移动：跟随的**取色放大镜** + 就近**窗口磁吸**高亮
- 拖拽：自定义框选；单击命中窗口：吸附选取
- **右键**：复制光标处色值并退出
- **Esc**：退出

> 提示：这是覆盖全屏的截图层，进入后按 Esc 即可退出。

## 编译

需要现代 GCC（conda 自带的 mingw 5.3 太旧，会在 `d2d1.h` 触发编译器崩溃）。推荐便携版 **[w64devkit](https://github.com/skeeto/w64devkit)**：

```bat
build.bat
```

`build.bat` 默认调用 `C:\Users\kebia\tools\w64devkit\bin\g++.exe`；也可改成任意现代 g++ 或用 MSVC。

## 里程碑进度

- [x] **M1**：GPU 覆盖层 + 桌面捕获 + 变暗 + 选区/手柄 + 取色放大镜 + 窗口磁吸 + 右键取色
- [x] **M2**：工具栏 + 矩形 / 圆角矩形 / 椭圆 + 颜色/粗细 + 复制到剪贴板 + 保存 PNG(Ctrl+S) + 撤销(Ctrl+Z)/Delete
- [x] **M3**：彗星箭头（拖画 + 拖中心绿点弯折）+ 马赛克笔刷（方/圆 + 3 档大小，GPU 位图画刷像素化）
- [x] **M4**：文字（DirectWrite + 思源宋体/站酷快乐体 下拉）+ 要素选中/移动/换色 + Delete 删除 + 确认后自动粘贴
- [ ] 余项：箭头旋转手柄、更多细节打磨

> 注意：文字功能依赖 exe 同目录的 `fonts/`（思源宋体 / 站酷快乐体）。分发时请连 `fonts` 文件夹一起。

### M4 操作
- **文字**：选文字工具，在选区内点一下出现输入框，输入后 **Enter 提交 / Shift+Enter 换行 / Esc 取消**；子栏可切**字号(3档) + 颜色 + 字体(思源宋体/站酷快乐体)**
- **选中/移动**：点击已画的要素即选中(绿框)并可拖动；点调色板给它**换色**；按 **Delete** 删除
- **完成✓ / 右键取色**：复制后自动在光标处 **Ctrl+V 粘贴**

### M3 操作
- **箭头**：在选区内拖拽画彗星箭头；画完后中点出现**绿色控制点**，拖它可弯折成拐弯箭头
- **马赛克**：选中后子栏可选**方/圆**笔刷、3 档大小；在选区内涂抹即打码（GPU 位图画刷，边涂边显）

### M2 操作
- 框选后出现工具栏：**矩形 / 圆角矩形 / 椭圆 / 撤销 / 取消✕ / 完成✓**
- 选中工具后下方出现**粗细(3 档) + 颜色(6 色)**子栏
- 在选区内拖拽绘制；**✓** = 复制到剪贴板并退出；**Ctrl+S** = 保存 PNG；**Ctrl+Z / Delete** = 撤销

对比要点：同样移动鼠标、拉框、放大镜，观察 CPU 占用与跟手程度与 Python 版的差异。
